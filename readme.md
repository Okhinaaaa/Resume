# A/B Testing & Causal Inference Cases

Данный репозиторий содержит два проекта, демонстрирующих навыки проведения продуктовых экспериментов и оценки причинно-следственных эффектов с использованием современных статистических методов.

В проектах реализован полный аналитический цикл: от подготовки данных и проверки качества эксперимента до статистической проверки гипотез и интерпретации результатов.

---

# Проект 1. Анализ A/B-теста изменения скидочной политики маркетплейса

## Цель проекта

Провести полный анализ результатов A/B-теста и определить влияние изменения размера скидки на пользовательское поведение и бизнес-метрики.

## Что реализовано

### Подготовка данных

- первичный EDA;
- анализ структуры датасетов;
- поиск пропусков и дубликатов;
- проверка качества данных;
- анализ распределений.

### Очистка данных

Выполнена подготовка данных перед анализом:

- удаление выбросов;
- обработка крупных ("оптовых") покупателей;
- анализ пользователей с нулевым выкупом;
- формирование корректной аналитической выборки.

### Проверка корректности эксперимента

Перед анализом результатов была выполнена валидация A/B-теста:

- проверка отсутствия пересечения пользователей между группами;
- проверка гомогенности экспериментальных групп;
- анализ баланса основных метрик;
- оценка корректности рандомизации.

### Статистический анализ

В работе используются классические методы анализа продуктовых экспериментов:

- доверительные интервалы;
- bootstrap;
- permutation tests;
- непараметрические критерии;
- оценка статистической значимости различий;
- расчет uplift;
- интерпретация бизнес-эффекта.

### Итог

По результатам анализа сформирована аналитическая записка с выводами и рекомендациями относительно запуска изменения в продакшен.

# Проект 2. Causal Inference: Synthetic Control Method

## Цель проекта

Оценить влияние масштабного строительства тюрем в штате Техас на уровень преступности с помощью метода синтетического контроля (Synthetic Control Method).

Проект представляет собой пример применения методов причинно-следственного анализа (Causal Inference) к реальным панельным данным.

## Используемый подход

В отличие от классических A/B-тестов, экспериментальная рандомизация отсутствует.

Для оценки эффекта построен синтетический аналог Техаса из других штатов США, максимально похожий на него до момента вмешательства.

После этого проводится сравнение фактической динамики и синтетического контроля.

## Выполненные этапы

- подготовка панельных данных;
- исследовательский анализ;
- выбор предикторов;
- построение Synthetic Control;
- сравнение качества совпадения до интервенции;
- оценка эффекта после вмешательства;
- визуализация результатов;
- интерпретация причинно-следственного эффекта.

## Используемые методы

- Synthetic Control Method;
- панельные данные;
- анализ временных рядов;
- визуальный анализ контрфактического сценария;
- оценка причинного эффекта (Causal Effect).
