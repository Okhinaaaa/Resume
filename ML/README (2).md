# Machine Learning Projects

В этом разделе собраны учебные и командные проекты по машинному обучению с акцентом на решение прикладных аналитических задач.

## Подход

Полный цикл работы с моделями: исследовательский анализ данных (EDA), очистка и предобработка, feature engineering, выбор и сравнение алгоритмов, подбор гиперпараметров, валидация и интерпретация результатов.

## Технологии

**Python:** Pandas, NumPy, Scikit-learn, LightGBM, CatBoost.

**Методы:** EDA, Feature Engineering, Model Selection, Hyperparameter Tuning, Cross-Validation, Model Evaluation.
