# Product analyst & ML Portfolio

Портфолио учебных и командных проектов по продуктовой аналитике, причинно-следственному анализу и машинному обучению.

## Проекты

### A/B Testing & Causal Inference
- **A/B-тест скидочной политики маркетплейса:** подготовка данных, проверка корректности эксперимента, Bootstrap, permutation tests, оценка uplift и формирование продуктовых рекомендаций.
- **Synthetic Control:** оценка причинного эффекта строительства тюрем в Техасе на основе панельных данных и контрфактического сценария.


### Machine Learning
Проекты по разработке и оценке ML-моделей: EDA, предобработка данных, feature engineering, обучение, настройка гиперпараметров, валидация и интерпретация результатов.

## Стек

**Python:** Pandas, NumPy, SciPy, Scikit-learn, Statsmodels, LightGBM, CatBoost.  
**Методы:** A/B Testing, Statistical Inference, Causal Inference, Synthetic Control, Machine Learning.
